# Aniu UI 重构设计规范（供 GPT Image2 生成前端图）

> 用途：将当前 Aiu（A股 AI 模拟交易系统）的 Agent UI 改造成 Awwwards / FWA / CSS Design Awards 顶级水准的界面。
> 生成图片协议：请按本文件输出 **每一页 1 张完整界面 mockup**（桌面端宽屏 1440×900），连续生成，保持跨页一致的视觉语言。

## 一、全局设计语言（所有页面统一）

**视觉基调**：暗色专业交易终端 + AI 智能体气质。深色背景，柔和玻璃质感面板，克制的高亮点缀，信息密度高但不拥挤。

| 项目 | 规范 |
|------|------|
| 背景 | `#0B1020` 深靛蓝黑，带极轻微环境光渐变 |
| 面板 | 玻璃拟态，背景 `rgba(20,28,48,0.55)`，`1px` 描边 `rgba(148,163,184,0.14)`，`16px` 圆角，弥散阴影 |
| 主色 | 品牌青 `#38BDF8`（数据）＋ 涨跌色：红涨 `#F8524D` / 绿跌 `#22C55E`（**A股习惯：红=涨 绿=跌**） |
| 文字 | 主 `#E6EDF7`，次 `#A8B8D0`，弱 `#6E7F99`；数字用等宽字体 `JetBrains Mono` 保证对齐 |
| 字体 | 中文 `Inter / 系统黑体`，数字 `JetBrains Mono` |
| 圆角 | 面板 16px，卡片 12px，按钮 8px，微型标签 6px |
| 间距 | 基于 4px 栅格；面板内边距 20px |
| 图标 | **全部使用 Lucide 图标**（线性描边，1.75px stroke），**全界面禁止任何 emoji / 颜文字** |

**布局骨架（每页一致）**：
- 顶部全局栏 → 左侧 icon 导航 + 品牌 → 中部可滚动工作区
- 信息紧凑：多用「主数值 + 次级补充」的双行微型卡片，均衡横向排列

## 三、各页面功能分布（信息紧凑版）

### 1. 登录页 /login
- 居中卡片：`ChartLine` 图标 + **Aniu** 标题 + 副标题「AI 模拟交易系统」
- 密码输入框（`Lock` 图标）＋「记住密码」Switch + 「登录」主按钮
- 底部版权与版本号 v0.4.0
- 建议：加入账户状态预览或极简行情背景点缀

### 2. 账户总览 /overview
**顶部 5 个 KPI 微型卡片**（紧凑双行：主值＋次级值），横向排布，`ref` 即时换色：
1. **账户状态** — 主：运作天数；次：交易成功率（`Percent`）
2. **资金规模** — 主：账户总资产（`Wallet`）；次：初始资金
3. **仓位情况** — 主：总持仓市值（`PieChart`）；次：现金余额 · 总仓位比例
4. **累计表现** — 主：总收益金额（`TrendingUp`）；次：总收益率
5. **今日表现** — 主：当日盈亏（`Zap`）；次：当日收益率 · 今日交易次数

**正文三块数据表**（统一表格组件、列头大写弱化、数值等宽）：
6. **持仓情况**（`Briefcase`）列：名称/代码 · 持仓市值 · 股数/可卖 · 当日盈亏/率 · 总盈亏/率 · 当前价/成本 · 仓位占比
7. **交易信息**（`ReceiptText`）列：名称/代码 · 买入时间 · 卖出时间 · 成交股数 · 卖价/买价 · 卖额/买额 · 收益/率
8. **委托信息**（`ClipboardList`）列：名称/代码 · 委托时间 · 方向 · 委托价/量 · 成交价/量 · 状态徽标
- 右上角「刷新」按钮（`RefreshCw`），刷新时显示旋转，冷却期禁用

### 3. AI 分析 /tasks
**上半区：运行记录**（`History`）
- 分组「今日」「历史」；每个运行 = 迷你方块卡（状态点 + 类型标签 + 时间 + 耗时）
- 直播运行：呼吸光点 + 实时计时
- 历史支持日期选择器（`CalendarDays`）
- 顶栏右侧：**执行分析**（`Play`）＋**执行交易**（`Zap`）两个操作按钮，运行中变 loading

**下半区：分析详情**（选择后显示）
- 第一行三个信息桶（紧凑）：
  1. **运行状态** `Timer` — 起止时间 · 耗时 · token 输入/输出/总量
  2. **接口调用 (n)** `Cable` — 紧凑列表：工具名 + 摘要 + 状态点
  3. **交易执行 (n)** `Send` — 紧凑列表：买入/卖出标签 + 摘要 + 状态点
- 下方大输出区 `FileText`：Markdown 最终结论 / 原始返回联动预览
- 顶部「删除任务」`Trash2`

### 4. AI 聊天 /chat
- **左侧会话栏**（`PanelLeft`）：新建对话 `Plus`、搜索 `Search`、分组会话列表（持久会话 + 今日/近7天/更早），每项标题 + 时间，hover 显示删除 `Trash2`
- **中间对话区**：消息气泡（AI/用户），支持 Markdown 渲染、代码高亮、工具执行卡片（工具名 + 状态点）、附件预览
- **底部输入条** `MessageSquarePlus`：文本域 + 附件添加 `Paperclip` + 发送 `ArrowUp`，拖拽上传覆盖层
- 持久会话：只读历史浏览，禁止发送

### 5. 定时任务 /schedule
- **当前定时任务**卡片列（`Clock3`）：任务类别标签（交易/分析）+ 名称 + 交易日时间
- **下次运行**信息条：类别 · 名称 · 时间（`Timer`）
- **任务设置**分两区：
  - **分析任务**：盘前分析 `Sunrise` / 午间复盘 `Sun` / 收盘分析 `Sunset`，每卡含名称·描述·启用开关（Switch）
  - **交易任务**：上午运行 / 下午运行，每卡同上
- cron 表达式高级配置（`Braces`）

### 6. 功能设置 /settings
**左列：基础配置**
- Base URL（`Globe`）地址输入
- API Key（`KeyRound`）密码式输入
- 模型名（`Cpu`）＋ 最大上下文（数字步进）双字段
- 妙想密钥（`Sparkles`）密码式输入
- **资金上限（元）**（`Wallet` / `Coins`）数字输入，帮助文案：留空不注入提示词

**右列：系统提示词** `MessageSquareText`
- 大文本域；帮助文案：指导大模型行为

**下方加载区：技能管理** `Blocks`
- 统计：已安装 / 启用（运行时技能 · 标准技能）
- 导入 SkillHub 地址 + 本地上传 zip
- 技能卡片列表：名称 + 来源徽标 + 描述 + 启用开关 + 删除
- 顶栏「重新扫描」`RefreshCw`

## 四、标注入文（供 GPT 严格遵循）

- 深色专业交易终端美学，玻璃拟态面板，弥散阴影，极轻的纹理/噪点。
- 信息紧凑：优先「卡片网格 + 双行微型指标」，避免大段留白与浮夸装饰。
- 图标统一 **Lucide 线性图标**；**全程零 emoji**。
- 涨跌遵循 **A股习惯：红涨（#F8524D）绿跌（#22C55E）**；数字等宽 `JetBrains Mono` 对齐。
- 保持**跨页一致**：同一背景、同一面板样式、同一顶部栏 + 侧边导航骨架、同一表格组件。
- 达到 Awwwards / FWA / CSS Design Awards 每日最佳同级的设计完成度（视觉层次、动效克制、排版精修、状态清晰）。
- 动效：仅在 hover / 活跃态 / 直播运行使用克制的过渡与呼吸光效；无冗余交互动画。
